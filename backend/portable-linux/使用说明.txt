WebServerMonitor 社区版（勤加软件WEB服务器运维管理平台 · 开源版）
================================================================

【快速开始】
  1. 赋予执行权限并启动：
     chmod +x gateway *.sh
     ./启动平台.sh
  2. 浏览器访问 http://服务器IP:8080/
  3. 默认管理员：admin / admin123（首次登录请立即修改密码）

【以系统服务常驻（推荐生产使用）】
  sudo ./注册系统服务.sh        # 注册 systemd 服务：开机自启 + 崩溃 5 秒自动重启
  sudo ./卸载系统服务.sh        # 卸载服务（数据保留）

【目录说明】
  gateway          平台主程序（单文件，前端资源已内嵌，无任何外部依赖）
  config.yaml      配置文件（端口 / 数据库 / JWT 密钥 / guacd 地址）
  data/            运行时数据目录（SQLite 数据库与日志，自动创建）

【演示模式】
  无需真实服务器：添加服务器时主机填写 demo: 前缀（如 demo:web01）即可体验
  内置仿真引擎（6 台模拟服务器、6 种监控场景、危险命令拦截）。

【版本说明】
  本包为社区版（Apache-2.0 开源），无服务器数量与使用期限限制。
  企业版（高可用集群 / 审计合规增强 / LDAP-SSO）与品牌 OEM 定制请联系
  内蒙古勤加软件有限公司。

【安全提示】
  上线前请编辑 config.yaml，将 jwt.secret 替换为随机强密钥（openssl rand -hex 24）；
  该密钥同时参与 SSH/SFTP 凭据加密派生，更换后已保存的凭据需重新录入。
