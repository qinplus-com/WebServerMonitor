## 1. 产品概述

### 1.1 定位

勤加软件 WEB 服务器运维管理平台是一款面向企业的 **LINUX 服务器统一运维网关**，将 Web SSH 终端、SFTP 文件管理、网址可访问性监控、AI 智能助手、用户权限与审计日志整合为 **单文件 Windows 服务**，浏览器即开即用、零客户端。

### 1.2 技术架构

| 层级 | 技术 | 说明 |
| --- | --- | --- |
| 后端 | Go 1.x + Gin | 编译期通过 `go:embed` 内嵌前端静态资源 |
| 前端 | Vue 3 + Element Plus | 单页应用，路由懒加载 |
| 数据库 | SQLite（纯 Go 驱动） | `CGO_ENABLED=0` 静态编译，目标机无需运行库 |
| 认证 | JWT | 2 小时 token + 7 天刷新 token |
| 终端 | WebSocket + xterm.js | 浏览器与服务器双向实时通信 |
| 授权 | 社区版（开源构建） | 无授权流程，无服务器数量与期限限制 |

### 1.3 核心功能矩阵

| 序号 | 功能 | 说明 |
| --- | --- | --- |
| 1 | Web SSH 终端 | 浏览器直连 Linux，密码/密钥认证，选中复制、右键粘贴 |
| 2 | 多标签会话 | 同时连接多台服务器，并行操作互不干扰 |
| 3 | SFTP 文件管理 | 在线浏览、上传、下载、编辑服务器文件 |
| 4 | 网址可访问性监控 | 实时监控网站状态、延时、状态码、SSL 证书有效期 |
| 5 | AI 智能助手 | 免费 AI 提供操作系统级技术支持，可结合终端输出分析问题 |
| 6 | 权限与审计 | 多角色分级授权，服务器访问与操作全程记录审计日志 |
| 7 | 在线会话管理 | 实时查看与管理全部活跃终端连接 |
| 8 | 服务器集中管理 | 服务器信息、分组、网址、授权统一维护 |
| 9 | 远程桌面（Windows） | 一键生成本地 `.rdp` 或 H5 浏览器直连 Windows 桌面（Guacamole），免装客户端 |
| 10 | 演示模式 | `demo:` 前缀添加模拟服务器：6 台模拟主机、6 类监控场景、危险命令拦截，无需真实服务器 |

## 2. 安装部署

平台提供两种部署形态：**安装版**（`.exe`，Inno Setup 打包）与 **解压版**（`.zip`，免安装）。两种版本功能完全一致，仅部署方式不同。

### 2.1 安装版（推荐生产环境）

#### 2.1.1 安装步骤

双击 `勤加软件WEB服务器运维管理平台-安装版.exe` 启动安装向导：

| 步骤 | 说明 |
| --- | --- |
| ① 欢迎安装 | 点击「下一步」开始 |
| ② 许可协议 | Apache-2.0 开源协议，阅读后勾选「我同意此协议」 |
| ③ 版本说明 | 展示社区版与开源仓库信息（覆盖安装时自动跳过） |
| ④ 安装目录 | 默认 `D:\QinJiaGateway`，可自定义 |
| ⑤ 软件与服务名 | 设置显示名称（平台标题、快捷方式名）与 Windows 服务名（仅字母数字与 `_-`，1-64 位，不能数字开头） |
| ⑥ 数据目录 | 业务数据独立存放，默认 `C:\ProgramData\QinJiaGateway`，卸载不删除 |
| ⑦ 端口与管理员 | 访问端口（默认 8080）与初始管理员账号密码 |
| ⑧ 附加任务 | 勾选创建桌面快捷方式、开始菜单组 |
| ⑨ 准备安装 | 确认配置后点击「安装」 |
| ⑩ 安装完成 | 自动注册系统服务、添加防火墙规则、生成随机 JWT 密钥并启动 |

安装完成后，桌面将出现两个快捷方式：

- **平台浏览器访问**：使用专属图标，直接打开浏览器访问平台
- **平台管理工具**：`manager.ps1`（WinForms GUI），管理服务启停与备份

> 安装版若检测到已安装，会弹窗询问是否更新；点击「是」直接覆盖安装，保留旧 `config.yaml` 与业务数据目录。

#### 2.1.2 卸载

通过「控制面板 - 程序与功能」卸载：

- 停止并删除 Windows 服务
- 移除安装目录、快捷方式、开始菜单组
- 移除防火墙入站规则
- **保留** `C:\ProgramData\QinJiaGateway` 业务数据目录

### 2.2 解压版（无外网 / 绿色环境）

#### 2.2.1 文件清单

将 `勤加软件WEB服务器运维管理平台-解压版.zip` 解压到任意目录（单层结构）：

```
gateway.exe              主程序
manager.ps1              管理工具 GUI
manager.vbs              GUI 启动器（隐藏命令行窗口）
register-service.ps1     注册服务脚本
unregister-service.ps1   卸载服务脚本
启动平台.bat              前台运行
停止平台.bat              停止前台进程
注册系统服务.bat          注册为系统服务（自动 UAC 提权）
卸载系统服务.bat          移除系统服务
LICENSE                  Apache-2.0 开源许可证
qinplus.png              企业 Logo
```

#### 2.2.2 快速开始

1. 双击 `启动平台.bat`，平台启动后自动打开浏览器；
2. 默认访问地址：`http://localhost:8080/`；
3. 默认账号：`admin` / `admin123`（**首次登录后请尽快修改密码**）；
4. 双击 `停止平台.bat` 即可停止平台。

#### 2.2.3 注册为系统服务（推荐）

- 右键 `注册系统服务.bat` → **以管理员身份运行**（脚本自动 UAC 提权）；
- 服务名 `QinJiaGateway`，开机自启，崩溃后每 5 秒自动重启；
- 注册成功后自动创建桌面和开始菜单快捷方式；
- 卸载服务：右键 `卸载系统服务.bat` → 以管理员身份运行（数据保留）。

> 社区版（开源构建）无服务器数量与使用期限限制，安装版与解压版功能完全一致。

### 2.3 Linux 部署（tar.gz）

适用于 Linux 服务器 / 国产化环境（amd64，支持鲲鹏、飞腾等 arm64 架构源码编译）：

```bash
# 1. 解压并赋权
tar -xzf WebServerMonitor-社区版-1.0.0-Linux-x64.tar.gz
cd WebServerMonitor-社区版-1.0.0-Linux-x64
chmod +x gateway *.sh

# 2. 前台试运行（默认端口 8080）
./启动平台.sh

# 3. 生产环境注册 systemd 服务（开机自启 + 崩溃 5 秒自动重启）
sudo ./注册系统服务.sh

# 4. 卸载服务（数据目录保留）
sudo ./卸载系统服务.sh
```

- 默认管理员：`admin` / `admin123`（首次登录请立即修改）；
- 防火墙放行端口：`firewall-cmd --add-port=8080/tcp --permanent && firewall-cmd --reload`；
- 详细说明见包内《使用说明.txt》。

## 3. 配置说明

### 3.1 配置文件位置

| 版本 | 配置文件 | 数据目录 |
| --- | --- | --- |
| 安装版 | `<安装目录>\config.yaml` | `C:\ProgramData\QinJiaGateway`（可自定义） |
| 解压版 | `<exe 同目录>\config.yaml` | `<exe 同目录>\data` |

> 配置文件缺失时自动使用内置默认值，并支持环境变量 `QJ_PORT` / `QJ_ADMIN_USER` / `QJ_ADMIN_PASS` / `QJ_JWT_SECRET` 覆盖。

### 3.2 config.yaml 字段说明

```yaml
# 服务端配置
server:
  port: 8080              # 浏览器访问端口
  mode: release           # release / debug

database:
  driver: sqlite
  dsn: ./data/gateway.db  # 相对路径基于 exe 所在目录

jwt:
  secret: "随机字符串"     # 安装版自动生成随机密钥
  expire: 7200            # token 过期时间（秒），2 小时
  refresh_expire: 604800  # 刷新 token（秒），7 天

# 默认管理员账号（首次启动自动创建）
admin:
  username: admin
  password: admin123

# 软件品牌信息（安装时可自定义）
app:
  name: 勤加软件WEB服务器运维管理平台
  service_name: QinJiaGateway    # 仅字母数字与 _-

# 版本标识（社区版无授权流程，无需配置授权）
license:
  edition: community      # community | enterprise
```

### 3.3 端口与防火墙

- 修改端口：编辑 `config.yaml` 中 `server.port`，重启服务生效；
- Windows 防火墙：安装版自动添加入站规则；解压版需手动放行对应端口；
- 端口被占用时启动会失败，日志位于 `<数据目录>\logs\gateway-YYYYMMDD.log`。

## 4. 首次登录

1. 浏览器访问 `http://<服务器IP>:<端口>/`（如 `http://localhost:8080/`）；
2. 输入管理员账号密码（默认 `admin` / `admin123`）；
3. 登录成功后自动跳转至「运行概览」页面；
4. **强烈建议**立即在「用户管理」中修改默认密码。

> 登录页采用动态视频背景 + 玻璃拟态登录卡片，登录卡片边框带流动光带效果（conic 渐变 + mask 镂空），支持 Edge 浏览器保存密码功能。

## 5. 功能使用

### 5.1 运行概览（Dashboard）

登录后首页，集中展示：

- 服务器总数与在线统计
- 当前活跃终端会话数
- 最近登录与命令记录
- 网址可访问性监控汇总（平均延时、正常/异常网址数）
- 关键指标可视化图表

### 5.2 服务器管理

**路径**：左侧菜单 → 服务器管理

- **列表视图**：按分组折叠显示，每台服务器前有状态点（绿色在线 / 橙色临期 / 灰色离线）；
- **新增服务器**：点击右上角「新增服务器」按钮，填写名称、分组、主机 IP、端口（默认 22）、账号与认证方式（密码 / 密钥）；
- **服务器操作**：每行右侧提供「连接」（打开终端）、「文件」（打开 SFTP）、「编辑」、「删除」按钮；
- **分组管理**：管理员可创建/删除分组，将服务器归类；
- **网址管理**：管理员可为服务器关联可访问性监控的网址（用于 Dashboard 监控卡片）；
- **授权分配**：管理员可为普通用户分配可见服务器，控制访问范围。

### 5.3 Web 终端（SSH）

**路径**：左侧菜单 → Web 终端

- **建立连接**：点击标签栏「+」按钮，下拉选择已授权的服务器；
- **多标签**：可同时打开多个标签，连接同一台服务器或多台服务器并行操作；
- **交互方式**：选中即复制、右键粘贴（与原生终端一致），支持 xterm 全功能按键序列；
- **AI 联动**：可将终端输出送给 AI 智能助手分析；
- **会话保持**：WebSocket 断线自动重连，长时间空闲不会被动断开（除非管理员踢出）。

**常用运维命令示例**：

```bash
uname -a          # 内核版本
uptime            # 运行时长与负载
who               # 当前登录用户
df -h             # 磁盘使用情况
free -m           # 内存与交换分区
top / htop        # 进程与资源占用
netstat -tlnp     # 监听端口
iostat -x 1       # 磁盘 IO
```

### 5.4 AI 智能助手

**路径**：Web 终端页右侧 → AI 智能助手面板

- **本地大模型**：内置 Ollama，本地推理，无需外网；
- **操作系统级支持**：可询问 Linux 命令、Shell 脚本、故障排查、系统调优等；
- **结合终端输出**：可将终端最近输出粘贴给 AI 分析，快速定位问题；
- **免费使用**：不消耗任何云服务额度。

### 5.5 SFTP 文件管理

**路径**：左侧菜单 → 文件管理

- **双栏浏览**：左侧本地文件、右侧远程服务器文件；
- **上传**：将本地文件拖拽到右侧，或点击「上传」按钮；
- **下载**：选中远程文件点击「下载」；
- **在线编辑**：双击文本文件直接在线编辑保存；
- **权限查看**：右键查看文件权限、属主、大小、修改时间；
- **批量传输**：支持多文件选中批量上传/下载。

### 5.6 用户管理（管理员）

**路径**：左侧菜单 → 用户管理

- **账号管理**：创建、编辑、禁用用户账号；
- **角色**：管理员（全部权限）、普通用户（仅授权服务器）；
- **权限分配**：为普通用户分配可见服务器（仅能连接/查看被授权的服务器）；
- **密码管理**：重置用户密码；
- **登录历史**：查看用户登录记录。

### 5.7 在线会话（管理员）

**路径**：左侧菜单 → 在线会话

- 实时列出所有活跃 SSH 连接；
- 显示用户、服务器、连接时间、来源 IP；
- 一键踢出异常会话（防止账号被盗用或长期占用）；
- 与审计日志联动，可追溯会话中的全部命令。

### 5.8 审计日志（管理员）

**路径**：左侧菜单 → 审计日志

| 日志类型 | 记录内容 |
| --- | --- |
| 登录日志 | 账号、IP、时间、登录结果（成功/失败） |
| 命令日志 | 终端执行的全部命令及输出摘要 |
| SFTP 日志 | 文件上传/下载记录、操作人、文件名 |

- 支持按时间、用户、类型筛选；
- 支持导出 Excel 便于留档；
- 操作全程可追溯，满足合规审计需求。

### 5.9 网址可访问性监控

**路径**：运行概览页 → 网址监控卡片

- 后台每 60 秒自动检查所有监控网址；
- 卡片显示：状态点、域名、HTTP 状态码、延时、SSL 证书剩余天数；
- 状态配色规则：
  - 绿色：HTTP 200 且证书 > 30 天
  - 黄色：HTTP 200 但证书 ≤ 30 天
  - 红色：4xx / 5xx / 连接失败
  - 红黄蓝闪烁：证书过期或服务故障 + 证书 ≤ 30 天
- 异常卡片自动置顶；
- 支持钉钉告警（自定义群机器人 / 企业应用机器人）。

### 5.10 关于平台

**路径**：左侧菜单 → 关于

- 平台名称与 Logo；
- 8 大功能卡片流光展示（conic 渐变彗星沿边框循环）；
- 公司介绍与联系方式；
- 版权声明（加密存储 + 完整性校验，防止篡改）。

### 5.11 远程桌面（Windows 服务器）

**路径**：服务器管理 → Windows 类型服务器行 →「远程桌面」

添加服务器时「服务器类型」选择 Windows（默认端口自动联动 3389），即可对 Windows 服务器使用远程桌面，提供两种打开方式：

| 方式 | 说明 |
| --- | --- |
| 本地 RDP | 生成标准 `.rdp` 文件并下载，双击调起本地 mstsc 连接（不依赖任何服务端组件） |
| H5 | 浏览器内直接操作 Windows 桌面：剪贴板双向同步、窗口自适应缩放、全屏，免装客户端 |
| 复制地址 | 复制 `IP:端口` 供本地 mstsc 手动连接 |

H5 方式需先部署 [guacamole-server](https://guacamole.apache.org/)（guacd）：

```bash
docker run --name guacd -d -p 4822:4822 guacamole/guacd
```

并在网关 `config.yaml` 中配置 `guacd_addr`（默认 `127.0.0.1:4822`；置为 `-` 可禁用 H5 入口，本地 RDP 方式不受影响）。

> 会话建立使用 60 秒一次性令牌（token 用后即焚），服务器密码不落浏览器缓存；未配置密码的 Windows 服务器会拦截提示。

## 6. 管理工具

桌面快捷方式「平台管理工具」打开 `manager.ps1`（WinForms 原生 GUI，双击自动 UAC 提权）。

### 6.1 功能列表

| 功能 | 说明 |
| --- | --- |
| 服务启动 / 停止 / 重启 | 一键操作 Windows 服务，按钮状态与服务状态自动联动 |
| 实时状态 | 绿（运行）/ 橙（停止）/ 灰（未注册）三色标识 |
| 立即备份 | 自动停服务 → 备份数据库 → 自动拉起服务 |
| 恢复所选备份 | 校验文件完整性后恢复，避免数据损坏 |
| 打开平台网页 | 调用默认浏览器访问平台 |
| 打开数据目录 | 跳转到 `config.yaml` 配置的 `data_dir` |
| 打开配置文件 | 用记事本打开 `config.yaml` |
| 授权状态 | 显示当前版本（社区版）、服务器数量 |

### 6.2 备份目录

- 默认备份目录：`C:\ProgramData\QinJiaGateway\backups`；
- 可在管理工具中自定义备份目录（**拒绝**安装目录、平台数据目录、空路径、不存在目录自动创建）；
- 备份目录配置持久化于 `C:\ProgramData\QinJiaGateway\manager.conf`；
- 卸载重装平台不影响备份文件。

> 启动服务失败时弹窗会显示失败原因和日志路径（日志位于数据目录 `logs\` 下）。

## 9. 静默部署

安装版支持静默部署（无人值守安装），适用于批量分发：

```bat
setup.exe /VERYSILENT ^
  /APPNAME=顺和运维管理平台 ^
  /SVC=ShunHeOps ^
  /PORT=18100 ^
  /ADMIN=admin ^
  /PASS=YourStrongPassword ^
  /DIR="D:\ShunHeOps"
```

| 参数 | 说明 |
| --- | --- |
| `/VERYSILENT` | 静默部署，无界面 |
| `/APPNAME=` | 软件显示名称（平台标题、快捷方式名） |
| `/SVC=` | Windows 服务名（1-64 位、字母数字与 `_-`，不能数字开头） |
| `/PORT=` | 访问端口 |
| `/ADMIN=` | 管理员用户名 |
| `/PASS=` | 管理员密码 |
| `/DIR=` | 安装目录 |

> `/VERYSILENT` 模式跳过安装完成提示窗体，全自动部署；非静默模式安装完成时显示可多选勾选框（默认勾选「打开 Web 平台」和「打开服务管理工具」）。

## 10. 常见问题

### Q1：忘记管理员密码？

停止服务后，在程序目录执行重置命令（以下示例将 `admin` 重置为新密码）：

```bat
gateway.exe -set-admin-user admin -set-admin-pass 新密码 -config config.yaml -data "数据目录"
```

完成后启动服务即可用新密码登录。

### Q2：端口被占用？

修改 `config.yaml` 中 `server.port`，或通过环境变量 `QJ_PORT` 覆盖；同时在 Windows 防火墙放行新端口。

### Q3：服务启动失败（1053）？

查看数据目录 `logs\` 下当日日志定位原因（常见：端口被占用、数据目录权限不足）。

### Q4：数据目录在哪？

| 版本 | 数据目录 | 日志目录 |
| --- | --- | --- |
| 安装版 | `C:\ProgramData\QinJiaGateway` | `<数据目录>\logs\` |
| 解压版 | `<exe 同目录>\data` | `<数据目录>\logs\` |

### Q5：如何迁移平台？

1. 停止服务；
2. 复制整个数据目录到新机器；
3. 重新安装/解压平台程序；
4. 修改 `config.yaml` 指向新数据目录（或保持默认）；
5. 启动服务。

### Q6：浏览器访问白屏？

- 确认服务已启动（管理工具状态为绿色）；
- 确认端口未被防火墙拦截；
- 清除浏览器缓存或按 `Ctrl + F5` 硬刷新；
- 查看日志是否有启动错误。

### Q7：终端连接不上服务器？

- 确认服务器 SSH 服务已启动（`systemctl status sshd`）；
- 确认服务器 IP、端口、账号密码正确；
- 确认服务器防火墙放行 22 端口；
- 确认网关服务器到目标服务器的网络可达（`ping` / `telnet`）。
